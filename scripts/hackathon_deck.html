Problem Statement & Architecture

동산보험, 왜 시장 확대에 실패하는가?

1

획일적 보험료

자치구별 화재율 최대 3.2배 차이에도 동일 보험료. 저위험 고객은 이탈, 고위험 지역은 손실률 악화.
2

고객 세분화 부재

1인가구 청년과 4인가구 자영업자에게 같은 상품. 라이프사이클/자산/소득 미반영으로 전환율 저조.
3

약관 불투명성

14개 조항, 4개 규칙의 복잡한 상호참조. 상담사도 즉답 어려워 고객 이탈 + 컴플라이언스 리스크.
4

시장 기회 미포착

이사 시즌 동산보험 수요 급증을 실시간 감지 못함. 부동산 거래량 기반 교차판매 타이밍 놓침.

Insight & Recommendation #1

7단계 보험료 산출 엔진

핵심 인사이트

  • 기존 동산보험은 지역/고객 무관하게 정액 보험료 적용
  • 서울 25개구 화재율 편차 3.2배, 범죄율 편차 2.8배 확인
  • 5구간 비선형 리스크 커브로 위험도별 차등 적용 시 손실률 23% 개선 시뮬레이션

적용 기술

  • 순보험료 - 품목별 손해율 기반 기초 산출
  • 경험보험료 - 자치구별 실적 반영
  • 위험분류 - 5구간 비선형 커브 적용
  • 신뢰도보정 - Z = min(n/1082, 1.0)
  • 부담능력 - 월소득 0.5% 상한
  • 세그먼트 - 10 페르소나 조정
  • 최종승인 - 규정 준수 검증
기대 효과

지역별 위험도를 반영한 공정한 보험료 산정으로 저위험 고객 이탈 방지 + 고위험 지역 적정 보험료 확보. 7단계 전 과정이 투명하게 공개되어 금융소비자 보호 규정 준수.

Insight & Recommendation #2

Graph RAG 기반 약관 추론 AI 상담

핵심 인사이트

  • 보험 약관 14개 조항이 11개 데이터 소스, 4개 규칙, 2개 ML 모델과 복잡하게 연결
  • 단순 키워드 검색으로는 조항 간 상호 참조 관계 파악 불가
  • Graph RAG로 3-hop 연결 추론 시 관련 근거 자동 수집 가능

적용 기술

  • Vector RAG - 367개 약관 청크, e5-base-v2 임베딩, cosine similarity TOP-5 검색
  • Graph RAG - 31 노드 + 34 엣지, 6개 관계 타입 (REFERENCES, CALCULATES, APPLIES, LIMITS, COVERS, PREDICTS)
  • LLM - Mistral-Large2 기반 답변 생성, 약관 원문 근거 강제 참조
  • BFS 탐색 - 3-hop 이내 연결 경로 자동 추출
기대 효과

"보험료가 왜 이 금액인가요?" 질문에 약관 조항 + 데이터 근거 + 산출 규칙을 연결하여 답변. Hallucination 방지 + 컴플라이언스 리스크 제거. 상담사 업무 부담 대폭 경감.

Insight & Recommendation #3

10 페르소나 세분화 + 시장 인텔리전스

핵심 인사이트

  • 동산보험 고객을 5차원(라이프사이클, 자산소비, 주거, 직업, 위험성향)으로 분류
  • 10개 대표 페르소나별 맞춤 상품/보장한도/리스크 팩터 자동 적용
  • 부동산 거래량 Z-Score 이상치 탐지로 이사 시즌 교차판매 타이밍 자동 포착

적용 기술

  • Cortex ML FORECAST - 화재 발생률 시계열 예측 (95% 신뢰구간)
  • ANOMALY_DETECTION - 부동산 거래량 급등 자동 감지
  • SENTIMENT - 소비자 사고 심각도 자동 분류
  • Cortex Analyst - 자연어 쿼리 ("강남구 평균 동산 가치는?")
  • REGR_SLOPE - 추세 기울기 분석
기대 효과

사회초년생에게는 소액 필수보장, 자영업자에게는 고가품 확장보장 등 페르소나별 최적 상품 자동 추천. 이사 시즌 사전 감지로 교차판매 전환율 향상. 시장 규모 자치구별 자동 산출.
